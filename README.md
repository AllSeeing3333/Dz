# Волна — прокат сапбордов

Приложение для учёта клиентов, инвентаря и аренды сапбордов на городском озере.

## Автор
Баранов Никита, группа 9/3-РПО-24/1

## О проекте
Тема: Прокат. Название заведения: «Волна» — это прокат сапбордов на городском озере. Это место, где жители и туристы могут взять сапборд (SUP-доску), весло и жилет на час или на день. Приложение нужно администратору проката, чтобы быстро оформлять аренду, видеть, какие доски свободны, и не терять учёт. От других прокатов «Волна» отличается тем, что делает акцент на семейный отдых: есть детские доски и скидки для больших компаний.
